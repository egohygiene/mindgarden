# Diagram style prompt reference

> Draw a readable modular knowledge-system diagram using the Mindgarden tokens.
> Use near-black botanical surfaces or the accessible light companion, pale text,
> restrained green connectors, thin labelled icons and generous panel spacing.
> Show direction and ownership explicitly. Use seed/orbit motifs sparingly.
> Preserve readable labels, clear hierarchy and a complete text alternative.

Distinguish observed, proposed and unavailable components in words as well as
visual treatment. Diagrams summarize canonical contracts and never grant data,
execution, publication or review authority. Do not invent deployed services or
include private source text, credentials or physical storage locations.

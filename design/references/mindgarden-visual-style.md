# Visual reference

Observed sources: [README banner](../../docs/assets/mindgarden-banner.png) and
[architecture illustration](../../docs/assets/mindgarden-architecture.png).
The banner uses near-black green surfaces, a single growing seedling, a luminous
orbital ring, thin horizontal traces and quiet, widely spaced lettering. The
architecture image uses lime-green outlines, thin icons, restrained panels and
clear input-to-output structure over a dark botanical ground.

The token palette is an interpretation for usable interfaces, not sampled image
pixels. Dark colors use deep green-black backgrounds, pale text and a lime accent.
The companion light palette uses pale botanical surfaces and dark forest links.
Both have explicit muted text, control borders and focus colors with measured
contrast. Never infer sensitivity, confidence or review authority from color.

Keep reading areas calm and spacious. Reserve orbital/seedling motifs for identity
or diagrams; avoid glows behind body text. Thin lines may decorate panels, while
interactive controls need visible boundaries and a strong focus ring. Icons have
readable labels and never carry meaning by color alone. Use local/system sans
fonts for reading and monospace for exact source identifiers; wide tracking is
reserved for short display text.

Motion is optional and reduced-motion preferences win. Reading width, wrapping,
44-pixel touch targets and keyboard navigation take precedence over decorative
symmetry. Mobile layouts stack surfaces and retain a textual graph alternative.
Future visual changes edit the tokens/reference first, then rebuild consumers.

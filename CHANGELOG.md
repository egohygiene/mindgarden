## [0.1.0] - 2026-11-06

### Added

- Standalone dependency-free Python CLI/library with deterministic v1 garden
  initialization, migration, validation and preserved v0 compatibility.
- Immutable private source vault, normalized source/archive/PDF adapters,
  reviewable curation and private routing, scoped retrieval and bounded context.
- Rebuildable reviewed-public site/federation/portal projections, local registry
  recovery, source/media triage and offline restore/relocation proofs.
- Synthetic provider-switch recovery and reviewable release artifact preparation.

### Compatibility and upgrade

- This candidate remains pre-1.0. Existing v0 CLI/library and portable records
  remain supported; v1 commands require their explicit bindings/session inputs.
- Optional PDF/rendering integrations retain separate preparation and capability
  requirements. Provider accounts, Drive, hosting and databases are optional.
- Back up canonical records and source vaults before a reviewed migration. Keep
  immutable originals and the previous verified install to support rollback.
- No supported interface is removed in this candidate. Future deprecations name
  a replacement and removal horizon; release notes must disclose breaking changes.
